# 🎱 Neon Pool - Multiplayer Online

Um jogo de sinuca online estilo **8 Ball Pool** com visual neon moderno, multiplayer em tempo real e física realista. Funciona como site hospedado no GitHub Pages e permite jogar com amigos de computadores diferentes.

## 🎮 Características

### Visual & Interface
- 🎨 **Aesthetic Neon**: Interface moderna com luzes neon quentes, rosa, verde e ciano
- 🎪 **Bar Theme**: Ambiente de bar noturno elegante
- ✨ **Efeitos Suaves**: Animações fluidas e glows realistas
- 📱 **Responsivo**: Funciona em PC, tablet e celular

### Mecânicas de Jogo
- 🎯 **Física Realista**: Colisões, atrito, elasticidade autêntica
- 🎱 **6 Buracos**: Padrão profissional de mesa de sinuca
- 👀 **Sistema de Mira Avançado**: Linha de mira, reticle dinâmico
- 💪 **Barra de Força**: Controle preciso da tacada
- 🔄 **Rotação de Bolas**: Efeitos de spin e rotação

### Multiplayer Online
- 🌐 **Multiplayer em Tempo Real**: Jogar com amigos em computadores diferentes
- 🚪 **Salas Privadas**: Criar sala com código para amigos
- 💬 **Chat em Tempo Real**: Comunicação entre jogadores
- 🤝 **Modo Equipes**: 1v1, 2v2, 3v3, Free For All

### Backend
- 🔥 **Firebase Realtime**: Sincronização em tempo real (upgrade futuro)
- 📡 **Modo Offline**: Jogar solo contra IA
- 🎮 **Modo Treino**: Praticar mecânicas
- 🤖 **IA Inteligente**: Oponentes com dificuldade

## 🎯 Como Jogar

### Jogar Agora (Offline)
1. Abra o jogo
2. Clique em "👏 Treino" ou "🎱 Jogar Agora"
3. Use mouse para apontar e disparar

### Jogar Online (Em breve)
1. "🔧 Criar Sala" ou "🚪 Entrar em Sala"
2. Compartilhe o código com amigos
3. Comece a jogar!

### Controles
- **Mouse**: Aponte o taco
- **Click & Arraste**: Defina força (distância = força)
- **ESC**: Pausa
- **💬**: Chat
